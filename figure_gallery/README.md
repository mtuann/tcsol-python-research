# V2 Figure Gallery

The figure gallery is a reusable collection of academic visualization examples created by the course.

Each completed V2 module should contribute at least one polished figure here.

## Gallery Categories

- `comparison/`
- `distribution/`
- `relationship/`
- `time_change/`
- `uncertainty/`
- `coded_text/`
- `multi_panel/`
- `interactive_to_static/`

## Required Figure Record

Each gallery item should include:

- final image;
- source notebook link;
- dataset link;
- chart type;
- research question;
- caption;
- why the chart fits the claim;
- common mistake the redesign avoids;
- export format notes such as PNG/SVG/PDF, size, and DPI.

The gallery should become the learner's visual memory bank: examples to imitate when writing papers.
