# MODULE_XX Assignment

## Submit

1. Completed notebook.
2. Cleaned or analysis-ready table.
3. Final paper-ready figure.
4. Caption.
5. Short Results or Methods note.
6. Reproducibility checklist.

## Tasks

### A. Inspect The Data

Describe unit of observation, key variables, missing values, and source.

### B. Prepare The Figure Table

Clean or transform the data so it supports the target chart.

### C. Build Two Candidate Figures

Create two possible visualizations and explain which one better supports the research claim.

### D. Export And Write

Export the final figure and write a caption plus a short paper-facing paragraph.
