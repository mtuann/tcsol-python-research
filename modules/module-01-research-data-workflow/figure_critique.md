# Module 01 Figure Critique

## Figure Under Review

Output: `outputs/figures/module01_source_readiness.png`

Claim it can support:

> Some data sources are better suited for a first beginner notebook because they balance source trust and manageable complexity.

## What Works

- The y-axis uses short source IDs, so labels remain readable.
- The score formula is stated in the x-axis label.
- Color separates readiness bands without requiring many legend items.
- The figure is exported as PNG, SVG, and PDF, so it can be used on the web and in paper workflows.

## What Must Be Explained in the Caption

- The score is a teaching heuristic.
- Higher score does not mean the source is universally better.
- Complex sources such as PISA may be academically excellent but not ideal for the first beginner notebook.
- Every source still needs definition checks, missingness checks, and citation notes.

## Common Bad Version

A weak version of this figure would:

- show only source names with no scoring rule;
- use decorative colors without meaning;
- omit source URLs and access dates;
- imply that a simple source is automatically a better academic source;
- export only a screenshot instead of reproducible figure files.
