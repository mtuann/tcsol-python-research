Create the first research output with Python

Ta đọc ba CSV nhỏ, kiểm tra bảng, tạo score đơn giản, xuất bảng summary, xuất figure và viết caption. Đây là workflow nhỏ nhất mà vẫn giống research paper workflow thật.

We read three small CSV files, inspect tables, create a simple score, export a summary table, export a figure, and draft a caption. This is the smallest workflow that still resembles a real research paper workflow.

4. Create a source-readiness score

Codecalculation
sources["readiness_score"] = sources["trust_score"] * 20 - sources["beginner_complexity"] * 8

sources["readiness_band"] = pd.cut(
    sources["readiness_score"],
    bins=[-1, 35, 55, 100],
    labels=["needs preparation", "good with guidance", "good first source"]
)

summary = sources[[
    "source_id", "source_name", "research_track",
    "trust_score", "beginner_complexity", "readiness_score",
    "readiness_band", "figure_candidate", "paper_risk"
]].sort_values("readiness_score", ascending=False)
Đây là heuristic để học. Nó buộc người viết phải nói rõ: vì sao source này được xem là đáng tin, và vì sao nó khó/dễ cho người mới.
This is a teaching heuristic. It forces the writer to state why a source is trusted and why it is difficult or easy for a beginner.

6. Draft the caption

Caption outputMarkdown
Figure 1. Source readiness for a first Python research figure.
The score combines source trust and beginner complexity for six candidate data sources.
Higher values indicate sources that are easier to inspect in a first notebook while still supporting an academic paper claim.
The score is a teaching heuristic, not a formal data-quality metric; final source choice still requires checking definitions, missingness, ethics, and citation requirements.

Caption tốt luôn nói rõ scope: figure này giúp chọn nguồn dữ liệu để học workflow, chứ không xếp hạng chính thức chất lượng dữ liệu.

A good caption states scope: this figure helps choose sources for learning the workflow; it does not officially rank data quality.
