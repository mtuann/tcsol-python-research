# Module 01 Readings and Source Notes

Source check: 2026-06-09

## Required Source Documentation

1. [UNESCO UIS Bulk Data Download Service](https://databrowser.uis.unesco.org/documentation/bulk)

   Use this to understand why large official education datasets are often distributed as CSV archives and why Python/R is useful for programmatic processing.

2. [World Bank Indicators API Documentation](https://datahelpdesk.worldbank.org/knowledgebase/articles/889392)

   Use this as a first example of programmatic access to time-series indicators. The API is useful later for country-year comparisons.

3. [Our World in Data Grapher Chart API](https://docs.owid.io/projects/etl/api/chart-api/)

   Use this to see how a public visualization site exposes CSV data and metadata JSON. This is beginner-friendly because a chart URL can become a data URL.

4. [OECD PISA](https://www.oecd.org/pisa/)

   Use this as an example of a high-value but high-complexity academic data source. It is excellent for education policy research, but not ideal as a first raw dataset for beginners.

## Reading Task

Choose one source above and answer:

1. What is one possible unit of observation?
2. What file format or access method is available?
3. What would be easy for a beginner?
4. What would be risky for a paper?
5. What citation or source note would you need?

## Vietnamese Teaching Note

Ở tuần đầu, không cần yêu cầu học viên tải PISA hoặc UIS full dataset. Hãy cho học viên đọc source documentation, hiểu vì sao dữ liệu lớn phức tạp, rồi thực hành với CSV nhỏ trong module.

## English Teaching Note

In the first module, do not require learners to download full PISA or UIS datasets. Let them read source documentation, understand why large data is complex, and practice with the small CSV files in this module.
