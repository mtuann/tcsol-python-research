# Module 01 Rubric

Total: 100 points

| Category | Points | Strong submission |
|---|---:|---|
| Paper question and data inventory | 20 | Question is research-facing; inventory clearly states source, unit of observation, format, and risk. |
| Source reasoning | 20 | Trust and complexity scores are justified with specific source notes, not guesses. |
| Python execution | 15 | Notebook runs; data is read from CSV; outputs are saved to files. |
| Figure quality | 20 | Chart matches the planning claim, labels are readable, scoring rule is visible, and output is exported as PNG/SVG. |
| Caption and limitation | 20 | Caption names source/sample/measure/pattern and avoids overclaiming. |
| Reflection | 5 | Reflection identifies one practical next step and one remaining risk. |

## Common Deductions

| Issue | Deduction |
|---|---:|
| Figure has no clear scoring rule | -10 |
| Unit of observation is missing | -10 |
| Caption only describes appearance, not evidence | -8 |
| Source URL or access note missing | -8 |
| Notebook output cannot be reproduced | -10 |
| Uses identifiable private data in a public submission | resubmit required |
