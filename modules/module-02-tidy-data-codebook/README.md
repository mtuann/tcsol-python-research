# Module 02: Tidy Data and Codebook

Default learner page: [`index.html`](index.html)

Module 02 is the second V2 foundation module. It turns the Module 01 question "what does one row mean?" into a concrete data-processing workflow: inspect a wide table, define variables, reshape to tidy long format, and document every important column in a codebook.

## Vietnamese Summary

Học viên học cách biến bảng wide có các cột `pre_vocab_score`, `post_vocab_score`, `pre_speaking_score`, `post_speaking_score` thành bảng tidy long với các cột `learner_id`, `skill`, `time`, `score`. Sau đó học viên viết codebook để mỗi biến có type, role, unit of observation, allowed values và paper note.

## English Summary

Learners turn a wide table with `pre_vocab_score`, `post_vocab_score`, `pre_speaking_score`, and `post_speaking_score` into a tidy long table with `learner_id`, `skill`, `time`, and `score`. They then write a codebook where each variable has a type, role, unit of observation, allowed values, and paper note.
