# Module 02 Readings and Source Notes

Source check: 2026-06-09

## Required

1. [Hadley Wickham, "Tidy Data," Journal of Statistical Software](https://www.jstatsoft.org/article/view/v059i10)

   Use this as the conceptual anchor for tidy data: variables as columns, observations as rows, and values as cells. The course applies the idea in Python/pandas rather than R.

2. [pandas User Guide: Reshaping and Pivot Tables](https://pandas.pydata.org/docs/user_guide/reshaping.html)

   Use this for `melt`, `pivot`, and related reshaping operations.

3. [pandas `read_csv` API reference](https://pandas.pydata.org/docs/reference/api/pandas.read_csv.html)

   Use this when learners need to understand how CSV import handles paths, missing values, date parsing, and column selection.

4. [Harvard Biomedical Data Management: Data Dictionary](https://datamanagement.hms.harvard.edu/collect-analyze/documentation-metadata/data-dictionary)

   Use this as a practical data dictionary reference. It explains why variable documentation matters for future understanding and reuse.

## Reading Task

Choose one dataset in this module and answer:

1. What is the raw unit of observation?
2. What is the tidy unit of observation?
3. Which variables are categorical?
4. Which variables are ordinal?
5. Which variables are numeric?
6. Which variables must be mentioned in the Methods paragraph?
