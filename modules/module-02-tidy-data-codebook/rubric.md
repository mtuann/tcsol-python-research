# Module 02 Rubric

Total: 100 points

| Category | Points | Strong submission |
|---|---:|---|
| Unit of observation | 20 | Clearly distinguishes raw row meaning from tidy row meaning. |
| Codebook quality | 25 | Every key variable has type, role, allowed values, unit, and paper note. |
| Tidy transformation | 20 | Reshaped table is correct, readable, and figure-ready. |
| Figure quality | 15 | Figure uses tidy variables correctly and exports as PNG/SVG. |
| Caption and Methods note | 15 | Writing explains source, unit, variables, pattern, and limitation. |
| Reproducibility | 5 | Notebook runs and outputs can be regenerated. |

## Common Deductions

| Issue | Deduction |
|---|---:|
| Raw and tidy units are confused | -15 |
| Codebook lacks variable types | -10 |
| Ordinal variable treated as continuous without justification | -8 |
| Figure uses repeated wide columns directly without explanation | -8 |
| Caption omits limitation | -8 |
| Notebook cannot regenerate output files | -10 |
