# V2 Paper Package

This folder stores reusable templates and checklists for turning data analysis into paper-ready material.

V2 should teach visualization as part of academic writing, not as decoration.

## Planned Resources

- [`figure_checklist.md`](figure_checklist.md): publication-quality figure checklist.
- [`caption_templates.md`](caption_templates.md): caption patterns for comparison, distribution, relationship, time, uncertainty, and coded-data figures.
- [`results_sentence_frames.md`](results_sentence_frames.md): sentence frames for cautious quantitative interpretation.
- [`methods_data_description_template.md`](methods_data_description_template.md): how to describe data source, sample, unit of observation, variables, and cleaning.
- [`reproducibility_checklist.md`](reproducibility_checklist.md): notebook, data, environment, export, and citation checks.

## Final V2 Output

The final learner output should include:

- analysis-ready dataset;
- data dictionary;
- 2-3 paper-quality figures;
- caption for each figure;
- short Results section;
- reproducibility note;
- source and citation note.
