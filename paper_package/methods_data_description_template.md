# Methods Data Description Template

Use this paragraph frame when describing data in a paper.

> The dataset contains [number] observations at the level of [unit of observation]. Each row represents [row meaning]. The main variables used in the analysis are [variables], measured as [units/categories]. Data were obtained from [source] on [access date]. Before analysis, [cleaning steps] were applied. Records with [missingness rule] were [kept/excluded/recoded]. The cleaned dataset was used to create [figure/table], which supports the analysis of [research question].

Do not include private identifiers in public paper packages.
