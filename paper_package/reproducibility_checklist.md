# Reproducibility Checklist

Before submitting a figure package:

- The notebook runs from top to bottom.
- The raw or source data location is documented.
- The cleaned data table can be recreated.
- Output folders contain the expected figures and tables.
- Figure filenames match captions.
- Package versions or environment notes are recorded.
- Source URLs and access dates are listed.
- Private data is excluded or anonymized.
- A reader can identify which code cell generated each figure.
