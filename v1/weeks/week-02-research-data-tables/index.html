Tuần 02

Dữ liệu nghiên cứu dưới dạng bảng

Tuần này chuyển từ câu hỏi nhỏ sang thiết kế dataset: một dòng là gì, cột nào bắt buộc, và bảng đó sẽ hỗ trợ paper như thế nào.

Mở slides Mở demo Xem notebook HTML Chạy trong Colab

Khái niệm cốt lõi

Row

Một dòng là một đơn vị quan sát.

Column

Một cột là một biến hoặc thuộc tính.

Schema

Schema là danh sách cột và ý nghĩa của chúng.

Hỗ trợ viết paper

Output viết tuần này

Một data description 120-160 từ, dùng được cho phần Data/Materials.

Rủi ro thường gặp

Chỉ nói tên file mà không nói rõ một dòng đại diện cho điều gì.

Mẫu câu viết học thuật

The dataset is organized at the level of [unit of observation].
Each row contains [required columns],
which allows the study to [paper purpose].

Ghi chú bài học

Thuật ngữNghĩa thực hành

Thực hành

A. Read Schema

Chạy notebook và đọc data_unit, required_columns, paper_output.

B. Choose Plan

Chọn một track và giải thích một dòng dữ liệu là gì.

C. Data Description

Viết 120-160 từ mô tả dataset đầu tiên cho paper.

Bài nộp

Nộp một notebook chạy được, có table plan đã chọn, output CSV, source/privacy note, và data description 120-160 từ.
