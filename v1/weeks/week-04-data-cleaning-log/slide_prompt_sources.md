# Week 04 Slide Prompt and Source Log

## Visual Direction

Week 04 slides use the existing course slide system:

- large stage-first layouts;
- grid background;
- white cards with colored top/left accents;
- visible values and labels;
- no decorative abstract blobs;
- no raw Markdown backticks in slide prose.

## Generated Assets

No generated bitmap image was used for Week 04 slides. Visuals are original HTML/CSS tables, cards, and workflow diagrams.

## Prompt Used Internally

> Make data cleaning feel like a transparent research workflow, not a punishment for messy data. Show raw labels, standard labels, missing-value decisions, and the cleaning log as visible artifacts. Keep the learner focused on one workflow: diagnose, clean, log, export.
