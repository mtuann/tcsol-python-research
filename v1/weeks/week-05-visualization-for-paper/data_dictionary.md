# Week 05 Data Dictionary

Dataset: `data/raw/week05_cleaned_tcsol_scores.csv`

Teaching purpose: beginner practice for making paper-ready figures from a cleaned TCSOL classroom dataset.

Unit of observation: one learner's pre/post score record for one short activity.

Important: this is synthetic teaching data, not real student data. The file is derived from Week 04 cleaned output so Week 05 can focus on visualization.

## Source Note

Use this copy-paste frame in the assignment:

```text

```

| Column | Type | Meaning | Use in Week 05 |
|---|---|---|---|
| `learner_id` | text | anonymized learner ID | unit count and dot plot identity |
| `class_group` | category | class section A-D | optional stretch grouping |
| `activity_focus` | category | short-term teaching focus | main X-axis group |
| `pre_score` | numeric | score before activity, 0-100 | used to derive gain |
| `post_score` | numeric | score after activity, 0-100 | used to derive gain |
| `attendance_hours` | numeric | attended hours during the activity | not used in core figure |
| `completed` | yes/no/missing | whether the activity record is complete | analysis filter |
| `self_confidence` | numeric | self-rating 1-5 | optional future visualization |
| `gain_score` | numeric | `post_score - pre_score` | main Y-axis variable |
| `usable_pre_post` | boolean | completed with numeric pre/post scores | analysis filter |

## Standard Activity Labels

- `measure_words`
- `result_complements`
- `word_order`
- `vocabulary_review`

## Figure Rules

1. Filter to `usable_pre_post == True` before the core figures.
2. Report `N = 25` usable learner records in captions.
3. Use individual points when the sample is small.
4. Export figures with code, not screenshots.
5. Keep source/access note with the figure.
