# Week 09 Slide Prompt Sources

## Visual Design Prompt

Create a Vietnamese-first bilingual lecture deck for beginner Python research learning. Use a clean white/grid background, large headings, compact research cards, visible tables, and paper-style output frames. The deck should feel like an applied linguistics research workshop, not a programming bootcamp.
