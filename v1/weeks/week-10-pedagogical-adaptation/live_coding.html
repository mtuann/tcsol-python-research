2. Adaptation score

Score là heuristic lập kế hoạch: ưu tiên Week 09 + instructional need + communicative value - preparation load. Trong dataset này, learner_difficulty được đọc là nhu cầu hỗ trợ của giáo viên, không phải bằng chứng rằng item khó thì luôn nên dạy trước.

Worked example: A001 = 28 + 3*2 + 2 - 1 = 35.

In [3]
activities["adaptation_score"] = (
    activities["week09_priority_score"]
    + activities["learner_difficulty"] * 2
    + activities["communicative_value"]
    - activities["preparation_load"]
).round(1)

4. Group minutes với groupby()

groupby() giúp trả lời: lesson plan dành bao nhiêu phút cho từng phase?

In [5]
phase_order = {
    "review": 1,
    "notice": 2,
    "compare": 3,
    "controlled_practice": 4,
    "communicative_practice": 5,
    "feedback": 6,
    "assessment": 7,
}

# Step 1: keep only the model lesson rows.
plan = activities[activities["include_in_short_lesson"]].copy()

# Step 2: make a summary table: one row per lesson phase.
phase_minutes = plan.groupby("lesson_phase", as_index=False)["minutes"].sum()

# Step 3: sort phases in lesson order, not alphabetically.
phase_minutes["phase_order"] = phase_minutes["lesson_phase"].map(phase_order)
phase_minutes = phase_minutes.sort_values("phase_order").drop(columns="phase_order")

plan["phase_order"] = plan["lesson_phase"].map(phase_order)
plan = plan.sort_values(["phase_order", "activity_id"])

phase_minutes.to_csv(TABLE_DIR / "week10_phase_minutes.csv", index=False)
print(phase_minutes.to_string(index=False))

8. Pedagogical adaptation paragraph

Dùng table + figure để viết. Điền số liệu sau khi bạn đọc output.

Caption frame:

Figure 1 ranks candidate teaching activities by adaptation_score for 25 synthetic activity rows. The unit is one candidate activity. The score is a planning heuristic for teacher review, not evidence that the activity is effective.

Source note frame:

Source checked: ___ (accessed ___). It supports ___, but it does not prove this synthetic activity sequence works with real learners.

Paragraph frame:

Based on the activity-priority table, I would adapt the short lesson by focusing on ___. The lesson begins with ___, then moves to ___, and ends with ___. This recommendation is useful because ___. However, it remains a design recommendation because the dataset is synthetic and should be tested with real learner responses.
