# Week 10 Slide Prompt Sources

## Design Prompt

Create a Vietnamese-first bilingual slide deck for a beginner Python learner in TCSOL. Use the established clean grid style, large headings, compact data cards, visible ranking tables, and classroom lesson-plan visuals. The deck should feel like an applied teaching workshop, not a programming bootcamp.

## Sources Consulted

- Week 09 contrastive data and teaching priority tables.
- pandas `groupby()` and `sort_values()` documentation.
- Backward design teaching guide.
- ACTFL World-Readiness Standards.

## Asset Note

No external slide image, chart, CSS, or diagram is copied. Figures are generated from the Week 10 synthetic dataset.
