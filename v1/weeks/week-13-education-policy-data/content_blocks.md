# Week 13 Content Blocks

## Core Concept

A policy-data row is not just a quotation. It needs metadata: title, issuing body, date, source type, URL, access date, evidence type, code, and coder note.

## Beginner Analogy

Think of a policy coding table as a library catalog plus a research note. The catalog fields help someone find the source; the code fields explain why the source matters for your question.

## Method Warning

Policy description is not policy evaluation. A row can say that a policy mentions digitalization; it cannot prove that digitalization improved learning outcomes.

## Writing Move

Use cautious verbs: `mentions`, `emphasizes`, `reports`, `classifies`, `provides metadata for`. Avoid causal verbs unless you have outcome data and a research design.
