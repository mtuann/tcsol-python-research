# Week 14 Paper Package QA

## Core Package Questions

- [ ] Is the research question one sentence?
- [ ] Is the unit of analysis explicit?
- [ ] Is one dataset/table/figure clearly selected as main evidence?
- [ ] Does the caption include N, variables, and limitation?
- [ ] Are all web sources in Zotero or the source note?
- [ ] Does the learner know whether Word, Quarto, or Overleaf is actually needed?
- [ ] Can someone rerun the notebook and find the exported outputs?

## Stop Conditions

Stop formatting and return to research logic if:

- the paper has no clear question;
- the main figure/table has no caption;
- sources are not in Zotero or a source log;
- Overleaf becomes a distraction from missing prose;
- the learner cannot explain where data, notebook, and outputs live.
