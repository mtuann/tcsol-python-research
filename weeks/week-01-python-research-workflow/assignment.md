# Assignment: My First Research Notebook

## Goal

- Python skill: run a notebook, edit variables, read a small CSV file.
- Research skill: turn a broad topic into a small data-ready question.

## Data

- File: `data/raw/week01_research_tracks.csv`
- Unit of observation: one possible research project track.
- Key variables: `track`, `small_research_question`, `unit_of_observation`, `likely_output`.

## Core Tasks

Submit **one completed notebook**: `live_coding.ipynb`.

Inside the notebook:

1. Edit the personal research variables.
2. Run all cells from top to bottom.
3. Select one research track.
4. Keep or create one small summary table.
5. Write a 1-2 sentence caption.
6. Write one 100-150 word interpretation.
7. Record one limitation or question you still have.

The CSV-reading and table-export cells are sample code. In Week 01, you only need to run them and observe what they produce.

## Required Memo Structure

```text
Chosen track:
Small research question:
Data I would need:
Possible table or figure:
Limitation:
```

## Submission

- completed `live_coding.ipynb` only.

The notebook should contain the selected track, table/printed summary, caption, memo, and source/access-date note.

Caption reminder:

```text
Table 1. [What the table shows]. Data are from the Week 01 instructor-created teaching dataset, accessed 2026-06-03. N = [4 tracks or 1 selected track].
```
