Tuần 01: Python như một quy trình nghiên cứu

Đây là notebook nghiên cứu đầu tiên của bạn. Mục tiêu hôm nay không phải là thành thạo lập trình. Mục tiêu là chạy notebook, sửa vài giá trị an toàn, xem một dataset rất nhỏ, và kết nối output của Python với câu hỏi nghiên cứu.

Mục tiêu học tập

Cuối notebook này, bạn có thể:

  1. chạy các ô code từ đầu đến cuối;
  2. sửa các biến text đơn giản;
  3. đọc một tệp CSV nhỏ;
  4. chọn một hướng nghiên cứu;
  5. viết một diễn giải ngắn.

2. Đọc một tệp CSV nhỏ

Tệp CSV là một bảng được lưu dưới dạng text. Tuần này, mỗi dòng là một hướng project có thể phát triển.

In [2]
from pathlib import Path
from urllib.request import urlretrieve
import csv

possible_paths = [
    Path("data/raw/week01_research_tracks.csv"),
    Path("weeks/week-01-python-research-workflow/data/raw/week01_research_tracks.csv"),
]

data_path = next((path for path in possible_paths if path.exists()), None)

if data_path is None:
    data_path = Path("week01_research_tracks.csv")
    source_url = "https://raw.githubusercontent.com/mtuann/tcsol-python-research/main/weeks/week-01-python-research-workflow/data/raw/week01_research_tracks.csv"
    urlretrieve(source_url, data_path)
    week_dir = Path(".")
else:
    week_dir = data_path.parents[2]

print("Data file exists:", data_path.exists())
print("Data file path:", data_path)
Output
Data file exists: True
Data file path: weeks/week-01-python-research-workflow/data/raw/week01_research_tracks.csv
