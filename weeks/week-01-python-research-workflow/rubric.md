# Week 01 Rubric

Total: 100 points.

| Criterion | Points | What counts as good work |
|---|---:|---|
| Notebook runs | 20 | The notebook runs from top to bottom without broken cells. |
| Personal variables | 10 | The learner edits name, topic, research area, and question. |
| Data inspection | 15 | The learner runs the CSV sample code, counts rows, and explains what one row represents. |
| Research question | 15 | The selected question is small and connected to observable data. |
| Table/caption | 15 | The learner produces or copies a small summary table and writes a clear caption. |
| Interpretation | 15 | The memo states observation, possible use, and limitation in 100-150 words. |
| Reproducibility habit | 10 | The learner keeps the generated table from code, records source/access date, avoids private identifiers, and does not manually edit output files. |

## Beginner-Friendly Grading Note

Do not penalize the learner for not understanding every line of the CSV-reading code yet. In Week 01, success means:

- they can run code;
- they can edit safe parts;
- they can connect code output to a research idea.

## Week 01 Reproducibility Checklist

- Input path: `data/raw/week01_research_tracks.csv`.
- Output path: `outputs/tables/week01_selected_track_summary.csv`.
- Source: instructor-created teaching dataset.
- Access date: 2026-06-03.
- Sample size for full track table: N = 4 tracks.
- Sample size for selected-track summary: N = 1 selected track.
- Private data: none; learner should not replace `Your name` with a full legal name if the notebook will be public.
