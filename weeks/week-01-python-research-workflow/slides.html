Data habit

What does one row mean?

One row can be:

  • one learner;
  • one test answer;
  • one sentence pair;
  • one MT segment;
  • one coded policy excerpt.

Beginner rule: before writing code, say what one row represents.

Notebook

Markdown cells and code cells

Cell typeUse
