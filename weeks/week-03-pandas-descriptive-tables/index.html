summary = (
    complete
    .groupby("activity_focus")
    .agg(n_learners=("learner_id", "count"),
         mean_gain=("gain_score", "mean"))
    .reset_index()
)

Quy trình code tuần này

2. Prepare

Chọn cột, lọc completed == "yes", tạo gain_score.

3. Summarize

Dùng groupby để tính N và average gain theo activity_focus.
