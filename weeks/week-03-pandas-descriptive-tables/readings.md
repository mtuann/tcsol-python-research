# Week 03 Readings

Last source audit: 2026-06-03

## Required Technical Reading

1. pandas Getting Started: "What kind of data does pandas handle?"
   - Link: https://pandas.pydata.org/pandas-docs/stable/getting_started/intro_tutorials/01_table_oriented.html
   - Why: introduces `DataFrame` as table-like data.

2. pandas User Guide: Group by: split-apply-combine
   - Link: https://pandas.pydata.org/pandas-docs/stable/user_guide/groupby.html
   - Why: official reference for the `groupby` idea. Learner only needs the plain split-apply-combine idea this week.

3. pandas API Reference: `DataFrame.groupby`
   - Link: https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.DataFrame.groupby.html
   - Why: official function page; use it as a lookup source, not as beginner reading from top to bottom.

## Required Research/Writing Reading

1. Wickham, H. (2014). Tidy Data.
   - Link: https://vita.had.co.nz/papers/tidy-data.html
   - Why: Week 03 borrows one practical idea: rows are observations and columns are variables.

2. Zotero Word Processor Plugin Usage
   - Link: https://www.zotero.org/support/word_processor_plugin_usage/
   - Why: Word + Zotero setup begins in Weeks 3-5. This week only asks the learner to know where citation insertion will happen later.

3. Zotero Word Processor Integration
   - Link: https://www.zotero.org/support/word_processor_integration
   - Why: explains that word processor plugins are bundled with Zotero and are normally installed automatically.
