Select

Chọn cột là chọn bằng chứng

Paper không cần mọi cột raw. Nó cần cột trả lời câu hỏi.

score_columns = [
  "learner_id", "activity_focus",
  "pre_score", "post_score", "completed"
]
scores = df[score_columns]
Filter

Lọc dòng không phải xóa dữ liệu

Raw CSV giữ nguyên. Bảng mới chỉ dùng completed records để caption có N rõ.

complete = scores[scores["completed"] == "yes"].copy()
Raw dataN = 32
Summary dataN = 31
Derived column

Tạo cột gain_score

Một cột tính thêm phải được mô tả rõ trong caption hoặc Methods note.

complete = complete.assign(
  gain_score = complete["post_score"] - complete["pre_score"]
)
Gain được tính bằng post_score trừ pre_score trên thang điểm 0-100.
GroupBy

groupby = nhóm rồi tính

Đọc code bằng lời trước khi học thuộc cú pháp.

summary = (
  complete
  .groupby("activity_focus")
  .agg(n_learners=("learner_id", "count"),
       mean_gain=("gain_score", "mean"))
  .reset_index()
)
