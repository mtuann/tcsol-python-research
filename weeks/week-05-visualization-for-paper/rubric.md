# Week 05 Rubric

Total: 100 points

| Criterion | Points | Strong work |
|---|---:|---|
| Code correctness | 25 | Notebook runs top to bottom; dataset loads; usable filter, summary table, plots, and exports all work. |
| Figure choice | 20 | Bar chart and dot plot match the research question; small-N variation is visible. |
| Figure design | 20 | Axes, labels, title/caption support reading; color is intentional; no misleading scale or decoration. |
| Export quality | 10 | Required `.png` and `.svg` files are created by code in `outputs/figures`. |
| Research writing | 15 | Caption and interpretation report N, pattern, and limitation without causal overclaiming. |
| Reproducibility | 10 | Paths are stable; source/access date are recorded; outputs are generated by notebook code. |

## Common Deductions

- -15 if figures are screenshots instead of exported files.
- -10 if the plot omits axis labels.
- -10 if the interpretation makes a causal claim.
- -10 if the usable-row filter is hidden or missing.
- -5 if sample size is omitted from the caption.
- -5 if color is decorative and distracts from the data.

## Track-Specific Bonus Awareness

The core dataset is TCSOL, but the learner can earn instructor feedback credit by explaining how figure choice would change for:

- contrastive category frequencies;
- MTPE edit-distance or error-label comparisons;
- education policy document counts by year, region, or policy theme.
