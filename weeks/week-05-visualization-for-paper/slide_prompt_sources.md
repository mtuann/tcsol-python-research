# Week 05 Slide Prompt and Source Notes

## Visual Design Prompt

Use the Week 02/04 slide style as the standard:

- full-screen slide deck, not a card-based landing page;
- pale grid background, large readable headings, compact concept cards;
- restrained blue/green/amber/rose accents;
- no decorative orbs or unrelated illustrations;
- every slide has one teaching object;
- code blocks are short and readable;
- final slide includes links to demo, notebook, Week 05 overview, and home.

## Content Prompt

Teach a beginner how to create paper-ready figures from cleaned data:

1. explain exploratory chart vs paper figure;
2. choose a figure type from a research question;
3. make mean bar chart and individual dot plot;
4. label axes and report sample size;
5. export `.png` and `.svg`;
6. write caption and interpretation without causal overclaiming.
