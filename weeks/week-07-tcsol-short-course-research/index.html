Nghiên cứu TCSOL ngắn hạn

Tuần này biến một hoạt động Hán ngữ ngắn hạn thành mini teaching-study: target structure, learner task, rubric, classroom variables và Methods draft.

Mở slides Mở demo Xem notebook HTML Xem figure

Khung nghiên cứu

Câu hỏi nhỏ

Activity focus nào tạo ra learner-task evidence rõ nhất cho target structure?

Dữ liệu

30 synthetic learner task records; 28 usable records có rubric pre/post và teacher note.

Output

Variable map, rubric summary, activity summary, hai figures và Methods draft.

Ghi chú bài học

Tuần 07 học cách thiết kế evidence trước khi viết Results. Rubric là cầu nối giữa hoạt động dạy học và dữ liệu.

Workflow tuần này

1. Design

Chọn target structure, learner task và rubric.

2. Map

Xác định unit, grouping variable, rubric variables và difficulty code.

3. Write

Chuyển design thành Methods draft có limitation.

Output mẫu

Activity summary

Feedback cycle có total rubric gain mô tả cao nhất trong dữ liệu synthetic usable.

Methods focus

Đoạn viết định nghĩa unit, task, rubric, exclusion rule và limitation.

Đơn vị phân tích là một learner task record; activity focus là biến nhóm, không phải bằng chứng nhân quả.

Thực hành

A. Core Minimum

Chọn target structure, đọc rubric, xác định unit và viết Methods draft.

B. Guided Core

Chạy notebook để xuất variable map, summary tables và figures.

C. Stretch

Thêm một difficulty code và nối nó với source note.

Bài nộp

Nộp notebook, 3 bảng CSV, 2 figures, captions, Methods draft và source note.

  1. Filter usable_task == True.

  3. Tạo activity figure và criterion figure.
