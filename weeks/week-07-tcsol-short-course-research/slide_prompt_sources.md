# Week 07 Slide Prompt Sources

## Visual Direction

- Use Week 02/06 slide style: grid background, large clear title, restrained cards, strong blue/green/amber/rose accents.
- Keep the first slide as an applied research design board, not a marketing hero.
- Avoid dense prose; each slide should teach one move in the research loop.

## Prompt Notes

- Explain rubric as "consistent observation", not grading bureaucracy.
- Use a concrete target structure such as result complements or measure words.
- Include one slide that explicitly says: activity focus is not causal evidence.
- Include one slide that turns table/figure evidence into Methods prose.
