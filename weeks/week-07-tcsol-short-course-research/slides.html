Code

Gain = post score minus pre score

for stem, label in criteria:
    usable[f"{stem}_gain"] =
        usable[f"{stem}_post"] - usable[f"{stem}_pre"]
Ví dụ không cần code: accuracy pre = 2, post = 4, vậy gain = 2.
