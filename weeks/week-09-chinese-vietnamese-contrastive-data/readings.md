# Week 09 Readings

## Required

1. pandas `Series.str.contains` documentation. Focus on `pat`, `regex`, and `na` so you understand why a visible string check is not the same as linguistic interpretation.
   https://pandas.pydata.org/docs/reference/api/pandas.Series.str.contains.html

2. pandas `crosstab` documentation. Focus on how two categorical columns become a count table.
   https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.crosstab.html

3. Unicode Standard Annex #38: Unicode Han Database (Unihan). Use it as a reference example for structured Han-character metadata such as readings; do not treat it as a complete contrastive grammar.
   https://unicode.org/reports/tr38/

4. Universal Dependencies Chinese GSD and Vietnamese VTB pages. Use them only as examples of structured annotation projects; Week 09 does not require dependency parsing.
   https://universaldependencies.org/treebanks/zh_gsd/index.html
   https://universaldependencies.org/treebanks/vi_vtb/index.html

## Optional Contrastive Reading

- HCMUE Journal article page on Chinese-Vietnamese contrastive analysis. Use it as a model for how contrastive claims need explicit examples and limits.
  https://journal.hcmue.edu.vn/index.php/hcmuejos/article/view/3573?lang=en_US
