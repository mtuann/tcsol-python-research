# Week 13 Translation QA

## Terms To Keep Bilingual

| English term | Vietnamese support | QA note |
|---|---|---|
| metadata | siêu dữ liệu nguồn | Keep English in code/table contexts; explain in Vietnamese in notes. |
| coding scheme | hệ thống mã hóa | Do not translate as machine coding; this is qualitative coding. |
| evidence type | loại bằng chứng | Make clear that policy text, statistics, metadata, and method models are not the same kind of proof. |
| date basis | cơ sở ngày tháng | Use this term to separate publication date from access-date placeholder. |
| access date | ngày truy cập | Use in source notes for dynamic web pages and data portals. |
| Data/Methods paragraph | đoạn Data/Methods | Keep section name English because it maps to paper structure. |

## Common Bilingual Risks

- "Policy impact" should be translated as "tác động chính sách", but Week 13 does not measure it.
- "Source coverage" means "phạm vi nguồn trong sample", not "phạm vi bao phủ của chính sách".
- "Synthetic/paraphrased dataset" means the classroom CSV is for practice and does not replace original policy sources.
- "Access-date placeholder" is not a real publication date; captions must say this when using the timeline.

## Final Check

- [ ] Vietnamese default text explains the learner task without requiring NLP background.
- [ ] English mode does not leave Vietnamese-only rubric or practice instructions.
- [ ] Code terms match CSV column names exactly.
- [ ] The writing output is called Data/Methods paragraph, not Results paragraph.
