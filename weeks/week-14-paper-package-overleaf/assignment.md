# Week 14 Assignment: Mini Paper Package

## Core Submission

Submit:

1. `week14_package_audit.csv`
2. `week14_missing_actions.csv`
3. `week14_tool_decision_table.csv`
4. `week14_reference_status.csv`
5. `week14_package_readiness.png`
6. one 180-220 word mini paper package plan;
7. one 4-6 bullet reproducibility note;
8. one tool-route decision: Word + Zotero, Quarto, or Overleaf.

The notebook exports `week14_submission_plan.md` as a model. Rewrite it for the learner's actual paper.

## Core Steps

1. Open `live_coding.html` to understand the audit workflow.
2. Run `live_coding.ipynb` in Colab or locally.
3. Load `data/raw/week14_paper_package_inventory.csv`.
4. Check which source paths exist and which core items are missing.
5. Export audit and missing-action tables.
6. Read the tool-decision table.
7. Choose the default writing route.
8. Write the mini paper package plan.
9. Write the reproducibility note.
