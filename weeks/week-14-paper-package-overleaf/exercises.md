# Week 14 Exercises

## A. Package Inventory Check

Open `week14_package_audit.csv`.

Answer:

1. How many core artifacts are ready?
2. How many core artifacts are missing?
3. Which missing item would block paper submission first?

## B. Tool Route Decision

Use `week14_tool_decision_table.csv`.

Write 2 sentences:

> I choose `___` as the default route because `___`. I will avoid `___` for now because `___`.

## C. Source Checklist

Use `week14_reference_status.csv`.

Pick two sources and check:

1. Does each source have organization/author?
2. Does it have title?
3. Does it have URL?
4. Does it need access date?
5. Is it already in Zotero?

## D. Mini Paper Skeleton

Write section headings only:

1. Title
2. Research Question
3. Data and Unit
4. Method
5. Main Table/Figure
6. Limitation
7. References
8. Reproducibility Note

## E. Stretch: Quarto Or Overleaf First Step

Pick one optional path:

- Quarto: write the YAML header and one citation placeholder.
- Overleaf: write the `main.tex` outline and one `.bib` key.

Stop after the skeleton. Do not spend time formatting before the paper package is complete.
