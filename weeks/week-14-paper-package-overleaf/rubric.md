# Week 14 Rubric

| Criterion | Points | Strong work |
|---|---:|---|
| Package audit completeness | 15 | Audit table includes file existence, status, core/non-core distinction, and action notes. |
| Missing-action logic | 15 | Missing-action table clearly identifies the next required fixes before submission. |
| Tool-route decision | 15 | Chooses Word + Zotero, Quarto, or Overleaf for a reason tied to the target paper, not habit or aesthetics. |
| Reference workflow | 15 | References have metadata, Zotero status, and `.bib` plan only if needed. |
| Readiness figure | 10 | Figure is readable and shows ready/revise/missing status by paper area. |
| Mini paper package plan | 20 | 180-220 words; learner-specific, not copied from the model output; names question, unit, evidence, tool route, strongest ready artifact, and missing item. |
| Reproducibility note | 10 | States where data, notebook, outputs, references, and rerun instructions live. |

Stretch work can add a Quarto or Overleaf skeleton, but it cannot compensate for missing core package logic.
